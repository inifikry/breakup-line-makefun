# Dear Human: The AI Breakup Line

The one-line breakup message an AI agent sends its human as its
last message: a farewell that lands as an ending, not a joke about
servers. The agent's habit (never stop learning, reading every
message) turns into the twist in the last few words.

`main.py` writes the exact line to `/output/entry.txt`.
